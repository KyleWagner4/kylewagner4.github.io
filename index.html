Portfolio Analytics Dashboard

A fully live portfolio tracker built in Python with Streamlit and backed by a Supabase database. Features real-time price feeds, dynamic benchmark selection across nine indices (S&P 500, Nasdaq 100, Russell 2000, and more) plus any custom ticker, historical performance tracking, Monte Carlo simulation across 1,000 paths, Markowitz Efficient Frontier optimization, Sharpe ratio and drawdown analysis, correlation heatmaps, a live news feed per ticker, full transaction history with persistent storage, and one-click PDF report export.

Tool

SEC 10-K / 10-Q Financial Statement Analyzer

A Flask-based financial analysis tool that pulls structured XBRL data directly from SEC EDGAR filings, normalizes it across companies with different reporting conventions, and presents clean three-statement financials with computed ratios. Features single-company and side-by-side comparison mode with directional winner highlighting, a year-by-year dropdown, and 10-year trend charts across key metrics. Tested and debugged against five real companies spanning meaningfully different reporting profiles.

Python Flask SEC EDGAR XBRL Financial Statements Chart.js

Research

401(k) Revenue-Sharing Empirical Analysis

Reconstructed a full 7-step Stata empirical workflow in Python across 5M+ observations. Built a multi-level plan-fund panel dataset linking DOL Form 5500 filings with CRSP mutual fund data across 828 retirement plans. Replicated logit regressions with high-dimensional fixed effects and clustered standard errors, demonstrating that revenue-sharing funds are significantly less likely to be removed from 401(k) menus in plans with revenue-sharing arrangements.

Python Stata CRSP DOL Form 5500 Panel Regression Fixed Effects
